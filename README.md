# Calculator

A calculator built with HTML, CSS and JavaScript. Input is stored in a stack (LIFO),
so the delete key removes the most recent entry first, whether it is a digit or an operator.

## Run locally
Open `index.html` in a browser.

## Deploy with GitHub Pages
1. Push these files to a GitHub repository.
2. Repo -> Settings -> Pages -> Source: "Deploy from a branch" -> Branch: `main` / `(root)` -> Save.
3. Your site appears at https://YOUR-USERNAME.github.io/REPO-NAME/
